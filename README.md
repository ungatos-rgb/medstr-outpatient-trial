# 地域の外来チェック
Cloudflare Pages の Git 連携用の独立した静的サイト。公開ブランチは main、ビルドコマンドは空欄、出力先は public。公開対象は public 内のみ。
製品データのある開発PCで node export.mjs <保存フォルダー> を実行すると公開用の地域集計を再作成できます。Node.js の node:sqlite を使用。公開前に地域・年・施設数と人口分母を確認してください。公開用データ更新時は sw.js のキャッシュ名も更新します。
地域と診療科のリンク例は /?region=43203&topic=内科系。ホーム画面への追加はiPhoneでは共有メニュー、Androidではブラウザメニューから操作します。
